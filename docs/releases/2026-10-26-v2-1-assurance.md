## 信任與驗收界線

- 上述 `ui_acceptance=VERIFIED` **只適用於內建報時遊戲範例及列名的自動與人工宣告判準**。不能推論所有使用本 Harness 建立的 UI 都已驗收。
- Chromium 測試不是跨瀏覽器測試，亦非真人可用性或輔助科技實測。固定次數 Tab 巡覽與模擬的 forced colors／reduced motion 並不能完整證明 WCAG 遵循。
- Token 色彩對比檢查只涵蓋契約明確宣告的配對及簡化門檻，未實測真實動態畫面。
- `basis: stakeholder` 等欄位是**來源宣告**，無法獨立證明利害關係人的批准；收據雜湊不是惡意同權限操作者不可偽造的數位簽章。
- 新 `pipeline` CLI 產生契約收據與交接資料，**不會**自行執行原始碼實作、Kernel Gate 核准、UI 人工審查或正式發布。
- 歷史 [UI-Design-Harness](https://github.com/weiwei-alvin/UI-Design-Harness) README 已指向目前 UI Pack，但獨立 Repository **尚未設定 Archived**。
- Audit Console 本機 Web UI 仍在規劃中，尚未實作；詳見 [PLAN](../../PLAN.md)、[SPEC](../../SPEC.md) 與 [Deferred Items](../DEFERRED_ITEMS.md)。
